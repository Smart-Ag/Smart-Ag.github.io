## 📖 关于实验室

智能农业机器人实验室（Agrobot）致力于开发和研究用于现代农业的机器人和自动化系统。我们的研究涵盖农业机器人的设计、计算机视觉、智能控制、精准农业等多个领域。

**团队负责人**: 傅隆生教授
**机构**: [西北农林科技大学](https://www.nwafu.edu.cn/) (Northwest A&F University)  
**地点**: 陕西省杨凌区

### 主要研究方向

- 🤖 **农业机器人** - 设计与制造、动力学与控制
- 👁️ **机器视觉** - 图像处理、目标检测、3D重建
- 🎯 **智能控制** - 运动规划、轨迹控制、多智能体协同
- 🌾 **精准农业** - 高通量表型、产量预测、智能装备
